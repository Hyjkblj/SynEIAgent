# 动作示教与遥控命令

## 目标

- **示教**学会一个动作（如铁山靠）→ 转为 **若干基础遥控命令**。
- 移动端提供「大招按钮」：按下即执行该动作序列。

## 思路

1. **示教**：真人或真机示教，录得关节轨迹或末端轨迹。
2. **抽象**：把轨迹打成若干「基础命令」序列，例如：
   - 移动类：前进/后退/左移/右移、转向；
   - 姿态类：蹲下、站起、重心左/右；
   - 技能类：铁山靠、挥手、踢腿（每个对应一段预定义或学习得到的轨迹）。
3. **映射**：一个大招按钮 = 一个 command_id（如 `skill_tieshankao`）→ 对应一段动作序列或策略输出。

## 基础命令设计（示例）

| command_id | 含义 | 参数示例 |
|------------|------|----------|
| move_fwd | 前进 | 速度、时长 |
| move_bwd | 后退 | 同上 |
| turn_l / turn_r | 左/右转 | 角速度、时长 |
| squat / stand | 蹲下/站起 | - |
| skill_tieshankao | 铁山靠 | 可选方向、力度 |
| skill_wave | 挥手 | - |

## 实现要点

- **仿真侧**：在 Isaac Sim/Isaac Lab 中，一个「技能」可对应一段关节轨迹或一个子策略；RL 可对技能做 reward 设计。
- **真机侧**：同一 command_id 下发到真机，真机执行预录或策略生成的轨迹。
- **移动端**：UI 上大招按钮绑定 `command_id`，通过 WebRTC/HTTP 发送给真机或仿真。

## 与比赛要求

- 「动作示教和快速仿真」：示教数据 → 基础命令序列 + 仿真复现。
- 「移动端大招按钮」：即上述 command_id 的触发端。
