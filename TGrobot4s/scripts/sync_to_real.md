# 一键同步到真机

## 流程概要

1. **仿真侧**：在 Isaac Sim 中训练/验证策略，或使用示教得到的动作序列。
2. **导出**：将策略权重或轨迹导出为真机可执行格式（依优必选天工 SDK 而定）。
3. **传输**：通过 USB/网络将资源推送到真机或控制端。
4. **部署**：真机加载策略或轨迹，接受移动端/Agent 下发的 command_id 触发。

## 可选实现

- **策略**：ONNX / TorchScript 等格式，真机端用对应 runtime 推理。
- **轨迹**：JSON/CSV 关节角度或力矩序列，按时间戳回放。
- **命令**：移动端发 `skill_tieshankao` 等 command_id，真机查表执行对应轨迹或策略。

## 与比赛

- 仿真跑完 → 一键同步 → 真机可被移动端遥控并执行技能。
- Agent 通过 Cursor CLI 生成场景内特殊交互逻辑，可输出 command 序列或配置文件供真机使用。
